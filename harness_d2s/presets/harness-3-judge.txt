Use these transcription requirements as review criteria:
For prose preserve original words, languages, names, numbers, paragraph boundaries and column order. Use Markdown headings only for real headings, **bold**, *italic*, ~~strikeout~~ and <u>underline</u> for visible styles. Use the same inline notation inside table cells.

Repeat a merged header's text across the exact columns or rows it covers; do not invent extra columns. Preserve signs, decimal points, parentheses, units, repeated values, labels and notes. Keep independent side-by-side or stacked table sections separate; a repeated header after a spacer and a new measure starts a new table. Preserve footnotes as subsequent prose blocks.
Read damaged and image-only material from the source images. Never summarize, translate or omit content. Recheck the first/last rows and column alignment against the source images before submitting.
